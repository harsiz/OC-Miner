# OC-Miner (v2.2)

OmegaCases official mining software.

_just_ because it is official doesn't mean faster + more efficient alternatives can't be made! They certainly can be! This is just the implementation that I quickly put together.

## Prerequisites
(what you need):

- A GPU that supports OpenCL (quick test, can your PC run the Minecraft app? If yes, you have it, if no, you don't)

## Download:

Get it at **[Releases](/releases)**. The latest release, all for windows, macOS and linux.
In the future I will add web mining, but if you want it early, you can actually just pass in "web_miner" to a LLM and let it build one for you
(as long as you provide references to docs: [Miner documentation -- ripped from site](/agents/miner_documentation.md), [AI Agent specific documentation](agents/mining-pool-docs.md)
